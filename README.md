## 💻 Run Locally

Want to explore the portfolio on your machine?

### Prerequisites

- Node.js
- pnpm

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
cd YOUR_REPOSITORY_NAME
```

### 2. Install dependencies

```bash
pnpm install
```

### 3. Start the development server

```bash
pnpm dev
```

### 4. Open in your browser

Visit [http://localhost:3000](http://localhost:3000).

### 5. Build for production

```bash
pnpm build
```

## 🧭 How I Approach AI Engineering

- **Measure, don't just assume.** Model performance should be supported by evaluation, not impressive-sounding claims.
- **Build for failure.** Missing API keys, weak retrieval results, invalid inputs, and unexpected errors deserve deliberate handling.
- **Keep humans involved where it matters.** In high-stakes applications, AI should support informed decisions rather than automatically replace human judgment.
- **Go beyond the notebook.** A useful AI system needs more than a model — it needs reliable data pipelines, interfaces, APIs, and deployment.
